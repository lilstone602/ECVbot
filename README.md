# Instagram Bot Kontrol Paneli (Eğitim Amaçlı)

⚠ **UYARI:**  
Bu proje yalnızca eğitim ve teknik araştırma amaçlıdır. Instagram'ın Hizmet Şartları'nı ihlal etmek için kullanılmamalıdır. Bot kullanımı, hesaplarınızın askıya alınmasına veya kalıcı olarak engellenmesine neden olabilir.

---

## Proje Hakkında

Bu proje, PyQt6 kullanılarak geliştirilmiş bir Instagram otomasyon arayüzüdür. Temel olarak Android emülatörleri üzerinde çalışacak şekilde tasarlanmıştır ve çoklu cihaz yönetimi sağlar.

> **Önemli Not:**  
> Bu kod, yalnızca teknik demonstrasyon ve Python otomasyon tekniklerinin eğitim amaçlı gösterimi için paylaşılmıştır. Gerçek hesaplarda kullanılması kesinlikle önerilmez.

---

## Teknik Özellikler

- ✨ PyQt6 tabanlı modern kullanıcı arayüzü  
- 📱 Çoklu emülatör/cihaz desteği  
- ⏱ Zamanlayıcı ile planlı çalıştırma özelliği  
- 💾 Ayarların JSON formatında kaydedilmesi  
- 🔄 LDPlayer emülatör entegrasyonu  

---

## Kullanılan Teknolojiler

- Python 3.13.3 
- PyQt6 (GUI için)  
- ADB (Android Debug Bridge)  
- Opencv
- FFmpeg (Sonuçlandırılmadı)
- LDPlayer Console (isteğe bağlı)  

---

## Kurulum

1. Gereksinimleri yükleyin:

```bash
pip install PyQt6
```

2. ADB'yi sisteminize kurun ve PATH'e ekleyin.

3. (İsteğe bağlı) LDPlayer kurulumu yapın.

4. Projeyi çalıştırın:

```bash
python arayuz.py
```
